## Execution Units

### `PROC:main`
- **Entrypoint**: `src/htmldownloader/__main__.py:if __name__ == "__main__"` -> `src/htmldownloader/cli.py:main`
- **Lifecycle**:
  - Starts via `python -m htmldownloader`.
  - Parses arguments.
  - Checks for updates (HTTP GET).
  - Selects downloader.
  - Runs downloader.
  - Exits with status code 0 or 1.

## Communication Edges
- **Direction**: `PROC:main` -> `GitHub API`
  - **Mechanism**: HTTP/1.1 (GET) via `requests`
  - **Endpoint**: `https://api.github.com/repos/Ogekuri/HtmlDownloader/releases/latest`
  - **Payload**: JSON release data (tag_name)
  - **Evidence**: `src/htmldownloader/cli.py` (`_get_latest_version_from_github`)

- **Direction**: `PROC:main` -> `Target Website`
  - **Mechanism**: HTTP/1.1 (GET) via `requests`
  - **Endpoint**: User-provided URL
  - **Payload**: HTML content, Assets (images, css, js)
  - **Evidence**: `src/htmldownloader/cli.py` (`download_one`, `_fetch_soup`)

- **Direction**: `PROC:main` -> `PROC:playwright-driver`
  - **Mechanism**: IPC (Pipe/Stdio) via `playwright` driver
  - **Endpoint**: Local driver process
  - **Payload**: Playwright commands (launch, goto, eval)
  - **Evidence**: `src/htmldownloader/cli.py` (`sync_playwright`)

- **Direction**: `PROC:playwright-driver` -> `PROC:browser`
  - **Mechanism**: CDP (Chrome DevTools Protocol) over WebSocket/Pipe
  - **Endpoint**: Browser instance
  - **Payload**: CDP commands
  - **Evidence**: Implicit in Playwright usage

- **Direction**: `PROC:main` -> `Local Filesystem`
  - **Mechanism**: OS Syscalls (open, write, mkdir)
  - **Endpoint**: Output directory (`--to-dir`)
  - **Payload**: `document.html`, `toc.html`, `index.html`, `assets/*`
  - **Evidence**: `src/htmldownloader/cli.py` (Path operations)
